# UK SEO Phase 1 Plan

## Recommendation

**Safe to start Phase 1: YES, conditionally.** Start with technical, trust and existing-URL upgrades only.

## Keep

- `/` as brand/market entry.
- `/puppies` as the UK puppies hub.
- `/breeds` and the strongest existing breed pages.
- `/guides` and the strongest four guide routes after rewriting.
- Valid real listing routes under `/puppies/{slug}`.

## Upgrade first

1. Add sitemap and robots routes.
2. Repair or define the missing `/contact` path.
3. Replace stale US search options and dollar formatting with verified UK settings.
4. Add evidence-backed sourcing, health-record and contact information.
5. Add supported JSON-LD and breadcrumb parity.
6. Consolidate duplicate Biewer and Cavalier slugs.
7. Add ItemList/Product schema only after data supports it.

## First implementation wave

- Upgrade the top 10–15 existing breed routes listed in `UK-SEO-BREED-PRIORITY.csv`.
- Rewrite the four existing guides with distinct UK informational intent.
- Add only a small number of researched guide gaps.
- Strengthen hub → breed → listing → guide links.

## Location strategy

**City pages recommended now: NO.** Current data has no country, region, county or city fields. Collect real location data and establish non-doorway standards first.

## Do not do

- Do not create hundreds of breed/location combinations.
- Do not fabricate seller, breeder, health, review, rating or location data.
- Do not migrate URLs without redirect/canonical evidence.
- Do not index client-side filter combinations by default.
